# KeyS-GO
 
un app che permette di aggregare molteplici offerte in un unico posto in cui si puo scegliere l'offerta piu conveniente anche in base all'affidabilita del sito che ha messo in vendita il gioco.
inoltre, ci sono vaste funzionalita di cui l'utente puo usufruire(come per esempio le notizie).
