# Diagrammi UML / yUML

Questa cartella contiene i codici sorgente dei cinque diagrammi, divisi per argomento.

## File
- `01-account.txt` — account e profilo
- `02-ricerca-giochi.txt` — ricerca e confronto giochi
- `03-acquisti.txt` — acquisti e vantaggi
- `04-community-notifiche.txt` — recensioni, liste dei desideri e notifiche
- `05-amministrazione.txt` — assistenza, amministrazione e sistema

I file conservano il codice yUML fornito. I nomi `.png` indicati all'interno del testo sono i nomi previsti per le immagini esportate; le immagini PNG non sono incluse in questo pacchetto.
